# QM Salon landing page template

Free HTML/CSS landing page you can deploy as-is or restyle for your own product.

This package is the live **QM for Salon** page (Lateral Demo 08): one-page hero, features, pricing, and WhatsApp CTA.

## Quick start

1. Unzip this folder.
2. Open `index.html` in a browser.
3. Edit copy, prices, and images in `index.html` and `images/`.
4. Upload the folder to any static host (Vercel, Netlify, GitHub Pages, or a normal web server).

On Vercel, import the unzipped folder (or this GitHub repo) as a static project. No build step is required.

## What’s included

- `index.html` — the full landing page
- `style.css` — layout and theme
- `css/` and `js/` — slider, menu, and animation helpers
- `images/` — screenshots, icons, and client logos

Forms in this template are design-only. Wire them to your own backend, form service, or WhatsApp link before going live.
